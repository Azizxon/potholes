# Detection & Analysis Module

This module processes data to detect and analyze potholes using computer vision and ML.

## Components

- `models/` - ML model definitions and weights
- `processors/` - Image and signal processors
- `detectors/` - Pothole detection algorithms
- `classifiers/` - Severity and type classifiers
- `utils/` - Common utilities and helpers
- `config/` - Model and algorithm configurations

Refer to `.copilot-instructions.md` for detailed development guidelines.
