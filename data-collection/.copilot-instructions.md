# Data Collection Module - Copilot Instructions

## Module Purpose
This module handles the collection of pothole-related data including images, GPS coordinates, road conditions, and metadata from various sources like mobile devices, cameras, and sensors.

## Key Responsibilities
- Image capture and preprocessing
- GPS coordinate collection and validation
- Sensor data integration (accelerometer, gyroscope)
- Data quality validation and filtering
- Temporary storage before processing

### Common Patterns
```python
# Example data collection interface
async def collect_image_data(location: GPSCoordinate, metadata: dict) -> ImageData:
    """Collect image data with location and metadata."""
    try:
        # Validate inputs
        validate_gps_coordinate(location)
        
        # Collect data
        image = await capture_image()
        processed_image = preprocess_image(image)
        
        # Add metadata
        data = ImageData(
            image=processed_image,
            location=location,
            timestamp=datetime.utcnow(),
            metadata=metadata
        )
        
        # Validate collected data
        validate_image_data(data)
        
        return data
    except Exception as e:
        logger.error(f"Failed to collect image data: {e}")
        raise
```
