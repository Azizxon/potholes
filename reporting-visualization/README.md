# Reporting & Visualization Module

This module provides user interfaces and visualizations for pothole data.

## Components

- `web/` - Web dashboard components
- `api/` - REST API endpoints
- `reports/` - Report generation logic
- `visualizations/` - Chart and map components
- `templates/` - Report and email templates
- `static/` - CSS, JavaScript, and assets

Refer to `.copilot-instructions.md` for detailed development guidelines.
