# Database & Storage Module

This module manages persistent storage and data access for the pothole detection system.

## Components

- `models/` - Database models and schemas
- `repositories/` - Data access layer implementations
- `migrations/` - Database schema migrations
- `queries/` - Complex query implementations
- `indexing/` - Spatial and performance indexing
- `config/` - Database configuration files

Refer to `.copilot-instructions.md` for detailed development guidelines.
